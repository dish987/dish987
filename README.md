### 📂 Projetos em Destaque

### [Wade Brasil | CRUD - Sistema De Login - Requisições com Autenticação JWT]
* Um projeto da faculdade com um cliente real, nosso objetivo é criar um site dinâmico no qual se cria, atualiza e exclui produtos criado no Dashboard Admin.
* **Destaque:** Sistema de Login, com autenticação JWT e hash, integrado com o PostgreSQL
* **Funcionalidades:** Painel Administrativo - Gestão Completa de Produtos (CRUD) -  Upload de Imagens Integrado(Envio de imagens diretamente para o Cloudinary).
* **Segurança e Proteção de Rotas:**
*   Back-end: Middleware (verificarJWT) que barra requisições de modificação (POST, PUT, DELETE) sem um token válido no cabeçalho Authorization.
*   Front-end: Verificação de sessão na inicialização do dashboard; se o token não existir ou for inválido, o utilizador é redirecionado ao index.html.
* **Arquitetura:** API Restful: Separação clara entre rotas públicas (Público geral) e rotas privadas (Apenas para Administradores).

#### [[☕ Villa Do Café | Full-Stack Menu & Inventory]](https://github.com/dish987/Site-Cafe-)
Um sistema completo para cafeterias que une um cardápio digital dinâmico a um painel administrativo para gestão de estoque.
* **Destaque:** Implementação de um servidor **Node.js/Express** integrado ao **SQLite3** para persistência de dados.
* **Funcionalidades:** Dashboard administrativo (CRUD completo), upload de imagens de produtos via **Multer**, controle de estoque em tempo real e cálculo automático de margem de lucro.
* **Lógica:** O sistema marca automaticamente itens como "esgotados" no front-end quando o estoque chega a zero.
